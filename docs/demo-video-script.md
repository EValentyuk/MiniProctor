# Сценарий демо-видео MiniProctor

Длительность: **3-4 минуты**. Формат -- запись экрана + закадровая озвучка, для LinkedIn/TenChat. Запись через OBS Studio, Windows Game Bar (Win+G) или любой recorder. Разрешение 1080p, частота 30 fps достаточно.

## Перед записью

- Откройте Streamlit-приложение: `streamlit run src/app.py` -- должен подняться на `http://localhost:8501`.
- Закройте лишние вкладки браузера, оставьте только Streamlit.
- Откройте README на GitHub в соседней вкладке -- может пригодиться для финального шота.
- Подготовьте 1-2 размеченных клипа в `data/raw/`: `phone_in_hand.mp4` (хорошо показывает phone-детекцию) и `gaze_side.mp4` (показывает head pose).
- Прорепетируйте сценарий 1 раз без записи -- проверьте, что приложение отзывчиво и нет сюрпризов.

## Технические советы

- **Микрофон.** Минимум -- USB-микрофон или гарнитура, не встроенный ноутбука. Шум сильно портит впечатление.
- **Темп.** Не торопитесь, особенно в фрагментах про метрики. Зритель должен успеть прочитать таблицу.
- **Курсор.** Если recorder поддерживает -- увеличьте размер курсора или включите подсветку кликов. На 1080p мелкий курсор теряется.
- **Монтаж.** Самые длинные ожидания (анализ в Streamlit) можно сократить ускорением 4-8x.
- **Субтитры.** Если планируется LinkedIn -- большинство смотрит без звука, добавьте субтитры (YouTube автогенерирует, можно подправить и наложить).

## Чего избегать

- Не показывать `.env`, API keys, личные данные.
- Не открывать терминал с историей команд -- там могут быть посторонние команды из других проектов.
- Не показывать `MEMORY.md` крупным планом -- там личные заметки, которые в публичном демо ни к чему.
