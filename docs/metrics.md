# MiniProctor: сводная таблица метрик

Единый источник правды по всем детекторам и всем версиям моделей. Сырые данные -- в `data/metrics/*.csv`, сюда сведены агрегаты и сравнения.

## Методология

- **Ground truth** в `data/labels/ground_truth.csv` -- 13 интервалов нарушений по 5 типам событий, размечены через интерактивный разметчик `src/label_clip.py`.
- **Метрика -- покадровая.** Каждый кадр считается положительным или отрицательным для каждого типа события по ground truth. Предсказание детектора сравнивается покадрово.
- **TP** -- кадр положителен и в GT, и в предсказании. **FP** -- предсказан, но не размечен. **FN** -- размечен, но не предсказан.
- **Precision = TP / (TP + FP)**, **Recall = TP / (TP + FN)**, **F1 = 2 P R / (P + R)**.
- Прогон оценщика: `python src/evaluator.py --yolo-weights <path> --out <out_csv>`.

## Известные проблемы

1. **book FP-хвост на absent.mp4 (77 кадров).** Модель Pass 2 видит книги на полностью пустом кадре. Гипотезы лечения:
    - повысить conf threshold с 0.25 до 0.4-0.5 -- precision вверх, recall вниз;
    - добавить негативные примеры -- пустые кадры из clean_baseline в обучение без меток.
2. **no_face precision низкий из-за пересечения с book.** Когда экзаменуемый закрывает лицо книгой -- no_face срабатывает «справедливо», но в нашей разметке этот эпизод помечен как book. Архитектурное решение: считать ли это пересечение допустимым или вынести в отдельный класс «лицо закрыто объектом».
3. **gaze_away recall на gaze_down (0.523) ниже, чем на gaze_side (0.768).** Реальный наклон головы вниз в нашей записи был неравномерный, ниже порога pitch 15° в части кадров. Лечится либо снижением порога с риском роста FP, либо более качественной пересъёмкой.

## Скорость обработки

Замеры на CPU (face детекторы) + GPU RTX 3050 (YOLO inference):

| **Этап** | **Скорость, кадров/с** |
|:---|:---|
| MediaPipe Face Landmarker (CPU) | 50-70 FPS |
| YOLO inference (GPU, batch=1) | 100+ FPS |
| Полный анализ (face + YOLO + сборка событий) | 30-50 FPS |

Реальное время обработки 15-секундного клипа -- 10-15 секунд на RTX 3050.
