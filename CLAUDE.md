# Локальные правила проекта MiniProctor

## Цель проекта
Пет-проект по ML для портфолио. Домен -- прокторинг: наблюдение за экзаменуемым через вебку, детекция нарушений. Цель трудоустройства -- команда, разрабатывающая ПО для приёмки экзаменов в вузах и обучающих организациях.

## Порядок выполнения задач
1. Перед началом работы -- `TodoWrite`, разбить запрос на атомарные задачи.
2. Отмечать выполненное сразу, не батчить.
3. По завершении сессии -- зафиксировать результат в `MiniProctor-results.md`. Формат: дата и время, что сделано, какие файлы созданы/изменены, какие метрики получены.

Исключения: короткие ответы на вопросы без изменения файлов -- todo и лог не нужны.

## Лог сессий
- Файл: `MiniProctor-results.md` в корне проекта.
- Короткая сводка -- в `MiniProctor-results.md`, подробные трассы экспериментов -- в `docs/experiments/<дата>.md`.
- Заголовок записи лога -- системные дата и время в формате `## YYYY-MM-DD HH:MM`. Время берётся через `date "+%Y-%m-%d %H:%M"`, не придумывается.

## Стек
- Python 3.11+, venv в `.venv/`.
- OpenCV, MediaPipe, Ultralytics (YOLOv8), face_recognition / InsightFace.
- Streamlit для UI.
- Jupyter для ноутбуков.
- Vibe-coding -- активно использовать Claude Code для генерации кода, но всегда понимать, что он делает, и проверять метрики вручную.

## Структура
- `data/` -- датасеты, размеченное видео, ground truth. **Не коммитим в git** (большие файлы).
- `src/` -- исходный код детекторов, утилиты, UI.
- `notebooks/` -- Jupyter-ноутбуки для экспериментов.
- `docs/` -- документация, диаграммы, brief, отчёты по экспериментам.
- `.claude/skills/` -- локальные скиллы (ru-editor, archive-results-log и др.).

## Документация
- `README.md` -- краткая сводка для внешнего читателя (GitHub).
- `docs/brief.md` -- полная постановка задачи, план, риски.
- `docs/architecture.md` -- C4-диаграмма и архитектурные решения.
- `docs/experiments/` -- отчёты по экспериментам с метриками.
- `docs/metrics.md` -- сводная таблица метрик по всем детекторам.

## Git
